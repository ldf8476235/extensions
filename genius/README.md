# Genius Swap Helper

## 说明

`Genius Swap Helper` 是一个面向 `tradegenius.com` 交易页的 Chrome Extension。

它的核心能力不是通用脚本注入，而是围绕当前页面结构做了一条可执行的自动兑换链路：

- 自动识别可用来源代币
- 自动选择目标代币和 `BNB` 网络
- 自动点击 `MAX`
- 自动点击 `Confirm`
- 等待 `Confirmed`
- 自动点击 `Close`
- 支持按 `次数` 或按 `目标交易量` 两种模式运行

## 结构

### 1. 当前支持页面

扩展内容脚本仅注入以下页面：

- `https://www.tradegenius.com/trade*`


### 2. 当前自动兑换策略

当前版本内置的自动流转逻辑如下：

| 来源代币 | 目标代币 | 网络 |
|---|---|---|
| `USDT` | `USDC` | `BNB` |
| `USDC` | `USDT` | `BNB` |

选择规则：

- 会先读取可见代币列表
- 只优先选择**有实际可用数量**的来源代币
- 如果 `USDT`、`USDC` 同时可用，会优先选余额更大的那一项

### 3. 当前统计能力

悬浮窗当前会显示两个统计值：

- `总交易量`
- `今日交易量`

这两个值统一来自订单历史接口汇总：

- 接口：`/api/db/orderHistory`
- 统计范围：`status = success` 且 `order_type = MARKET_SWAP`
- 汇总字段：`grossUsd`

其中：

- `总交易量` = 历史成功兑换累计金额
- `今日交易量` = 当天 00:00 到当前时刻的成功兑换累计金额

## 使用说明

### 1. 打开交易页

进入任意支持的 `trade` 页面，例如：

- `https://www.tradegenius.com/trade`

页面加载后，会出现右下角悬浮窗。

### 2. 配置运行模式

悬浮窗支持两种模式。

#### 次数模式

适用场景：

- 已知要跑固定轮数
- 希望跑完自动停止

操作步骤：

1. 选择 `次数`
2. 输入循环次数
3. 打开开关

停止条件：

- 成功完成设定轮数后自动停止

#### 目标交易量模式

适用场景：

- 希望不断循环，直到当天交易量达到目标

操作步骤：

1. 选择 `目标交易量`
2. 输入目标值，例如 `1000`
3. 打开开关

停止条件：

- 会先读取一次真实的今日交易量作为基线
- 每轮成功后记录本轮兑换金额，做本地累计
- 当本地估算值达到目标时，再调用一次真实接口校验
- 只有**真实今日交易量达到目标值**后才会停止

### 3. 自动执行链路

每轮自动执行的实际步骤是：

1. 点击第一个 `Choose`
2. 选择来源代币
3. 点击第二个 `Choose`
4. 搜索目标代币
5. `hover` 目标行
6. 点击 `BNB` 网络
7. 点击 `MAX`
8. 点击 `Confirm`
9. 等待反馈卡片进入 `Confirmed`
10. 点击 `Close`
11. 等待页面恢复可执行状态
12. 随机等待 `3-5s` 进入下一轮

## 弹窗说明

### 1. 页面内悬浮窗

页面内悬浮窗是主控制面板，支持：

- 开关控制
- 模式切换
- 次数输入
- 目标交易量输入
- 总交易量 / 今日交易量展示
- 实时日志
- 可拖动
- 可缩放

### 2. 浏览器工具栏弹窗

点击浏览器工具栏图标后看到的 `popup` 是轻量入口，当前只保留：

- 开关状态
- 已执行次数

真正完整的配置能力在页面内悬浮窗，不在工具栏弹窗里。

## 日志说明

悬浮窗日志会输出关键步骤，例如：

- 当前流程方向
- 已点击哪个 `Choose`
- 搜索是否成功
- 是否已点击 `MAX`
- 反馈状态是 `pending` 还是 `confirmed`
- 本轮兑换金额
- 目标模式下的本地累计值
- 真实交易量校验结果

目标模式下，典型日志会包含：

```text
开始目标交易量模式，目标值: $1,000.00
启动前检查，今日交易量 $488.44 / 目标 $1,000.00
记录本轮兑换金额: $19.31
本地累计兑换金额 $19.31，估算今日交易量 $507.75 / 目标 $1,000.00
本地估算已达到目标，刷新真实今日交易量校验
真实值校验，今日交易量 $1,002.18 / 目标 $1,000.00
今日交易量已达到目标，停止执行
```

## 目录结构

```text
genius/
├── manifest.json
├── content.js
├── content.css
├── popup.html
├── popup.css
├── popup.js
└── README.md
```

文件职责：

- `manifest.json`
  扩展配置、注入范围、content script 注册
- `content.js`
  自动兑换主逻辑、悬浮窗逻辑、统计逻辑
- `content.css`
  悬浮窗样式
- `popup.*`
  浏览器工具栏弹窗


## 已知限制

### 1. 页面结构强依赖

当前实现依赖 TradeGenius 当前页面结构，包括：

- `Choose` 按钮文案
- 代币列表结构
- 网络选择浮层
- `Confirm / Close / Confirmed` 等反馈文案

如果站点 DOM 或文案有变化，自动流程可能需要同步调整。
